7. Issues Encountered

🔴 Thinking Mode Kills Speculative Decoding

Qwen3.5's thinking chains are unpredictable — DFlash acceptance drops to 45.6% (needs >60% to break even). Disabled via chat_template_kwargs: {"enable_thinking": false}.

🔴 SGLang MTP/DFlash Broken on 24GB (v0.5.12)

MTP: Qwen3_5ForConditionalGeneration missing from NEXTN auto-detect (PR #23859). DFlash: CUDA graph pre-allocation OOMs at all memory fractions.

🟡 WSL2 Filesystem Bottleneck

NTFS-mounted models via /mnt/ showed 9% CPU utilization and 10x slower loading. Always use native ext4 /home/ for model files.

🟡 DFlash Drafter Compatibility

Community GGUF drafters had missing tokenizer data or wrong architecture tags. Lucebox requires qwen35-dflash-draft arch — use their convert_dflash_to_gguf.py converter.

🟡 lm-evaluation-harness Not Viable for Server Benchmarks

tinyBenchmarks via local-chat-completions doesn't support loglikelihood. local-completions works but takes 10+ hours at 1 req/s. Replaced with 10-query quick quality check.
