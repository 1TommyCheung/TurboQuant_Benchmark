### 1. vLLM Baseline

```bash

  -v ~/.cache/huggingface:/root/.cache/huggingface \
```

## Thinking Mode

All benchmarks disabled thinking via `chat_template_kwargs: {"enable_thinking": false}` in API requests. For beellama, also set at server level with `--chat-template-kwargs '{"enable_thinking":false}'` (still emits empty `<think></think>` tags but no reasoning content — ~6 token overhead).

## Benchmark Client

All runs used `tqbench/benchmarks/generation/runners/eval_speed.py` with 150 prompts (50 short <100 tok, 50 medium 100-500 tok, 50 long 500-2000 tok). Temperature 0.0, streaming enabled. Prompts generated by `tqbench/benchmarks/generation/data/generate_prompts.py`.

## Lucebox-Hub — Qwen3.6-27B Q4_K_M

### Server run (via Python server.py + HTTP)
```bash
cd lucebox-hub && DFLASH27B_KV_TQ3=1 python dflash/scripts/server.py \
  --target models/Qwen3.6-27B-Q4_K_M.gguf \
  --draft models/dflash-draft-3.6-q8_0.gguf \
  --port 8082 --budget 28 --max-ctx 131072 --enable-thinking false
```
**Result:** 54.7 tok/s C=1, 9.08s lat p50, 23,484 MB VRAM, 7/7 quality

### Direct binary benchmark (bench_he.py — matching their README)
```bash
DFLASH_TARGET=/home/tommy/models/Qwen3.6-27B-Q4_K_M.gguf \
DFLASH_DRAFT=/home/tommy/models/dflash-draft-3.6-q8_0.gguf \
python dflash/scripts/bench_he.py --n-gen 256 --ddtree-budget 22
```
**Result:** 86.22 tok/s mean, 139.2 tok/s peak (HumanEval code completion, no thinking, no HTTP)
- Their claim: 129.5 tok/s mean on RTX 3090
- Our gap: WSL2 overhead + 2 zero-output prompts dragging mean + different model (Qwen3.6 vs 3.5)
- Excluding zero prompts: 108.3 tok/s mean (84% of claim)
